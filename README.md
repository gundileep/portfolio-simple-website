Personal Portfolio Website

This repository contains my personal portfolio website, designed to showcase my skills, projects, and interests as a web developer. The portfolio is built with HTML and CSS, making it lightweight, responsive, and easy to customize.

🚀 Features

About Me – A short introduction about who I am and what I do.

My Interests – A list of my hobbies and passions, like web development, reading, and photography.

Projects Section – Highlights my completed projects:

Amazon E-commerce Clone (Frontend built using React.js)

Travel Website (Frontend project demonstrating layout and design skills)

Contact Page – A simple way for people to connect with me.

Social Media Links – Direct links to Instagram and LinkedIn.

📂 Project Structure
portfolio/
│
├── index.html      # Main portfolio page

🎯 Purpose

This project serves as my online resume and demonstrates my ability to create simple, elegant, and structured web pages. It’s a starting point for my future projects and an easy way for others to get to know me.
